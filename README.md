# FullStack

This is where I keep all the work from my fullstack bootcamp. Every folder is a lesson or a project I built along the way, starting from plain HTML and slowly working up to full React apps.

I've grouped the folders by course section so it's easier to find things (and honestly so it stops being one giant messy list). It's still a work in progress, I organize each section as I finish it.

## Sections

- **Intro to Web Development** - the basics: HTML, CSS, box model, calc, and getting comfortable with layout.
- **JavaScript & Algo** - core JavaScript plus the algorithm and data-structure exercises. Functions, array methods, `this`, callbacks, and a bunch of practice problems.
- **JavaScript & Web Development** - making JS talk to the browser and the network: the DOM, fetch/AJAX, promises, async/await, local storage, and the Tweeter and RUPG projects.
- **React** - coming soon. Still waiting on grades before I move these in and tidy them up.

Anything sitting in the root that isn't in a section yet is stuff I haven't sorted, mostly the React lessons and a few extras.

## Tech I've worked with

HTML, CSS, JavaScript, Node, jQuery, React, MobX, React Router, and Jest for testing.
